# NexTalk

Клиент-серверный мессенджер на C++ с отдельным Python AI-сервисом для будущего
анализа вложений.

## Что уже работает

- TCP-сервер на POSIX-сокетах.
- Консольный TCP-клиент.
- Переиспользуемый сетевой слой клиента для будущих интерфейсов.
- Регистрация аккаунта и логин по паролю.
- Личные сообщения между двумя онлайн-пользователями.
- Отправка сообщений пользователям offline с сохранением в истории.
- SQLite-хранилище пользователей, диалогов и доставленных сообщений.
- Загрузка истории личного диалога через `/history`.
- Отдельный поток клиента для приема входящих сообщений.
- Отдельный поток сервера на каждого подключенного клиента.
- Логирование старта/остановки сервера, входов, подключений, отключений и сообщений.
- Запуск в локальном режиме через `127.0.0.1` и в сетевом режиме через IP сервера.

## Структура проекта

- `client/` - клиентская часть на C++.
- `server/` - серверная часть на C++.
- `common/` - общий протокол и общие структуры.
- `ai_service/` - AI-сервис на Python.
- `docs/` - документация по архитектуре и протоколу.

## Сборка

```bash
cmake -S . -B build
cmake --build build
```

Если в системе установлен Qt6 Widgets, CMake дополнительно соберет
экспериментальный графический клиент `nextalk_gui`. Без Qt обычные цели
`server` и `client` собираются как раньше.

## Запуск

Сервер:

```bash
./build/server/server 5555 0.0.0.0 server.log nextalk.db
```

Клиент на той же машине:

```bash
./build/client/client 127.0.0.1 5555

```

Графический клиент, если установлен Qt6:

```bash
./build/client/nextalk_gui
```

В GUI укажите host, port и login, нажмите `Connect`, затем выберите или введите
собеседника. История выбранного диалога загружается кнопкой `Load history` и
автоматически при выборе чата после подключения.

При первом входе отметьте `Create new account`, чтобы создать пользователя и
задать пароль. Старые пользователи из базы без пароля могут таким же способом
задать пароль при первом запуске новой версии.

Клиент с другой машины или виртуалки:

```bash
./build/client/client <ip-сервера> 5555
```

Команды клиента:

```text
/msg <user> <text>  отправить личное сообщение
/history <user> [n] показать последние сообщения с пользователем
/login <user>       сменить логин
/help               показать команды
/quit               выйти
```

Для проверки можно открыть три терминала: один для сервера и два для клиентов.
Первый клиент логинится как `alice`, второй как `bob`, затем `alice` отправляет:

```text
/msg bob Привет
```

Историю диалога можно запросить так:

```text
/history bob 20
```
