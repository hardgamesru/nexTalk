# NexTalk

NexTalk - клиент-серверный мессенджер для UNIX/POSIX с C++-сервером, C++-клиентом
и веб-фронтендом на Vue + Vite.

Проект сделан как курсовая с фокусом на:

- работу в локальном и сетевом режиме;
- личные сообщения между пользователями;
- постоянное хранение данных и логов;
- расширяемую архитектуру.

## Что реализовано

- TCP сервер на POSIX socket API (`socket`, `bind`, `listen`, `accept`, `select`, `recv`, `send`).
- Многопоточность:
  - сервер: отдельный поток на каждого подключенного клиента;
  - консольный клиент: поток приема сообщений + поток пользовательского ввода.
- Регистрация и вход по паролю.
- Личные чаты (1:1), создание и удаление диалога.
- История сообщений (SQLite), в том числе для offline-сценария.
- Непрочитанные сообщения на сервере (`conversation_reads`, `mark_read`).
- Логи сервера с сохранением между сессиями:
  - старт/остановка сервера;
  - подключение/отключение;
  - вход пользователя;
  - обработка и доставка сообщений;
  - ошибки хранилища.
- Веб-клиент (Vue + Vite) через локальный WebSocket-TCP bridge.

## Структура репозитория

- `server/` - C++ сервер.
- `client/` - C++ клиент (`client`) и опциональный Qt клиент (`nextalk_gui`).
- `common/` - общий протокол (парсинг/сериализация).
- `web/` - Vue-фронтенд и bridge (`web/bridge/server.mjs`).
- `docs/` - документация для отчета и сдачи.
- `ai_service/` - отдельная заготовка под AI-сервис (не участвует в основном чате).

## Требования

- CMake >= 3.20
- C++17 compiler
- SQLite3 dev library
- POSIX-система (Linux/macOS/FreeBSD)
- Для web:
  - Node.js 18+
  - npm

## Сборка C++ части

```bash
cmake -S . -B build
cmake --build build
```

Если установлен Qt6 Widgets, дополнительно соберется цель `nextalk_gui`.

## Запуск сервера

```bash
./build/server/server 5555 0.0.0.0 server.log nextalk.db
```

Аргументы:

`server [port] [bind_address] [log_path] [db_path]`

Примеры:

- локальный режим: `127.0.0.1`
- сетевой режим: `0.0.0.0`

## Запуск консольного клиента

```bash
./build/client/client 127.0.0.1 5555
```

Команды:

- `/msg <user> <text>`
- `/history <user> [n]`
- `/chats`
- `/help`
- `/quit`

## Запуск Qt клиента (если собрался)

```bash
./build/client/nextalk_gui
```

## Запуск web-клиента

1. Запустить сервер C++:

```bash
./build/server/server 5555 127.0.0.1 server.log nextalk.db
```

2. Запустить bridge:

```bash
cd web
npm run bridge
```

3. Запустить Vite:

```bash
cd web
npm run dev
```

4. Открыть адрес Vite (обычно `http://localhost:5173`).
